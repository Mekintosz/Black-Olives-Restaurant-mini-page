# Black Olives Restaurant – Single Page Experience

A modular, webpack-bundled restaurant homepage that renders Home, Menu, and Contact views on demand. The page highlights the Black Olives brand with custom styling, image assets, and accessible navigation.

## Live Demo

- Production build: https://mekintosz.github.io/Black-Olives-Restaurant-mini-page/

## Tech Stack & Deployment

- JavaScript (ES modules, DOM-first rendering, accessibility hooks)
- CSS3 with custom properties, responsive layout, and custom web fonts
- Webpack 5 for asset bundling and GitHub Pages deployment
- Assets optimized for the `dist/` bundle served via GitHub Pages

## What It Does

- Renders dynamic Home, Menu, and Contact sections via tab-like navigation without page reloads
- Uses route metadata to manage button state, update document titles, and drive content rendering
- Applies responsive styling and semantic markup for a polished landing experience on desktop and mobile

## Local Development

1. Install dependencies: `npm install`
2. Build once: `npm run build`
3. Develop with watch mode: `npm run watch`
4. Deploy to GitHub Pages (requires configured remote): `npm run updateghl`

The production bundle lives in `dist/`, generated by webpack from the source files under `src/`.

## Skills Gained

- Refined modern JavaScript skills: route configuration, renderer injection, and DOM diff minimization with `replaceChildren`
- Improved module organization and reuse with helper factories for UI fragments
- Enhanced accessibility by wiring `aria-current`, alt text, and keyboard-friendly controls
- Practiced asset pipeline management with webpack loaders and static deployments to GitHub Pages
